      Start with an AI chat

      1. Copy the prompt below. It already has your name and heritage filled in.
      2. Open your AI chat (ChatGPT, Gemini, Claude, Perplexity …), pick the model yourself, and paste it.
      3. Talk it through. It will ask a lot of questions instead of guessing. Answer them in any language or a mix. Send photos of a hand-drawn tree if you have one. Say "done" when you're finished. It checks open questions and any placeholders with you before making the file.
      4. Bring it back: import the CSV file it gives you, or copy its code block into Settings › Or paste it in.
      5. Finish in the app: add birthdays, take headshots with Take photo, add addresses and phones, then Export contacts (.vcf) to your phone.
